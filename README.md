# Charles Portfolio

A personal portfolio showcasing Charles's digital product, web development, and software engineering work. Built with React and Vite, with project case studies for TCI, BCC, Eddie, and Agri-Energy Connect.

## Requirements

- Node.js
- npm

## Getting started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server.
- `npm run build` — create a production build in `dist/`.
- `npm run preview` — serve the production build locally.
- `npm run lint` — run Oxlint.

The portfolio includes both `/work/...` and `/projects/...` routes for its case studies.
